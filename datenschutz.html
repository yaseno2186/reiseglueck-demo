Datenschutz

Platzhalter · Demo-Projekt

Diese Datenschutzhinweise beschreiben, wie die Demo-Website technisch funktioniert. Für eine echte Website muss eine vollständige Datenschutzerklärung mit Verantwortlichem, Rechtsgrundlagen, Hosting-Anbieter und Betroffenenrechten erstellt werden.

Keine Cookies, keine Tracker

Diese Website setzt keine Cookies, nutzt keine Analyse- oder Werbe-Tools und lädt keine Inhalte von fremden Servern. Schriften, Bilder und Skripte liegen auf demselben Server wie die Website. Deshalb gibt es auch kein Cookie-Banner.

Formulare senden nichts

Buchungsanfrage, Beratungsanfrage und Bewertungsformular sind Demos. Beim Absenden werden keine Daten an einen Server übertragen.

Speicherung in Ihrem Browser

  • sessionStorage (Buchungsanfrage): Während Sie die Buchungsstrecke ausfüllen, speichern wir Ihre Eingaben im sessionStorage Ihres Browsers, damit nichts verloren geht, wenn Sie zurückgehen oder die Seite neu laden. Die Daten bleiben auf Ihrem Gerät, werden nach dem Absenden gelöscht und verschwinden automatisch, wenn Sie den Tab schließen.
  • localStorage (Demo-Bewertungen): Eine Bewertung, die Sie schreiben, wird im localStorage Ihres Browsers gespeichert und nur Ihnen angezeigt. Sie können sie löschen, indem Sie die Website-Daten in Ihrem Browser entfernen.

Server-Logs

Platzhalter · Hosting

Der Hosting-Anbieter (z. B. GitHub Pages) kann technisch notwendige Zugriffsdaten wie IP-Adresse und Zeitpunkt protokollieren. Angaben zum Anbieter und zur Speicherdauer folgen in der echten Version.
